# 收舖 Closing Time

A 60-second first-person horror walk through a 1989 Hong Kong cha chaan teng after closing. From the 港詭古 series 《地府通用》.

Play: https://howardhwt.github.io/closing-time/

- Scene: a Gaussian-splat reconstruction made with PINOC (Viggle) from one photo of a real cha chaan teng.
- Character: 祥哥, a rigged PINOC splat character generated from two reference images, playing a PINOC library idle clip.
- Engine: `@viggle/splat-engine` on PlayCanvas 2.18.

Controls: mouse to look, WASD to walk, E or click to interact. Headphones on.

```
npm install
npx vite          # dev
npx vite build    # static build in dist/
```
